# beta.12 audit — what the Beta builds left inconsistent

2026-10-28, after 2.0.0-beta.11. Three read-only audits: library surfaces
(Sonnet), the game and the show (Sonnet), host / wire / Stage (Opus). Each
finding was traced in code unless marked *plausible*. The maintainer's own
items (bulk domain actions, the drag chip, two-group drag, domain counts) are
fixed in P26.1 and not repeated here.

Triage: **Fix** — a bug or a gap with one obvious answer. **Decide** — the
fix changes behaviour the maintainer should choose. Numbering is stable; refer
to items as A1, B3, C7.

## A. Host, wire and Stage

| # | What | Triage |
| --- | --- | --- |
| A1 | **Rule edits after Load never reach the Play.** The snapshot and its frozen settings are taken at `play_load`; the freeze only covers playing/paused. Edit Rules (Games tab or Control float) while *loaded*, then Start: the show scores by the old rules while Control shows the new. A later float edit can also write a stale copy over a Games-tab edit. Restart has the same class. No host-side freeze on `recipe_set_settings` either. | **Decide**: re-freeze at `play_start` (recommended — loaded means "not started yet"), or freeze from Load. |
| A2 | *Apply to original* (Board difficulty dialog) rewrites the library row and announces nothing for it — Board, list and detail show the old difficulty. The fake emits it, hiding the bug. | Fix |
| A3 | **Undo while paused un-pauses the Play** (Paused inside the inverted span is folded out; the clock counts the pause). | **Decide**: Undo keeps the pause (recommended), or Undo refused while paused. |
| A4 | Manage workspaces counts never refresh (`['catalog','workspace-counts']` matched by no invalidation). | Fix |
| A5 | Restart announces nothing: the Plays list, recent games and the operator's Play count miss the new Play. | Fix |
| A6 | A health item (and its *Repair*) survives a workspace switch for up to 30 s — and *Repair* then runs on the new workspace. *(plausible)* | Fix |
| A7 | The fake host differs from the real one: overlay apply-to-original, refusing a switch with a completed Play in Control, duplicate joining archived domains, copied games' overlay ids, move preview when refused. | Fix |
| A8 | `catalog_bulk_edit` Move to domain announces no domain change (masked today). | Fix |
