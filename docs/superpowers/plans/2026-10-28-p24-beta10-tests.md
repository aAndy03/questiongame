# P24 (beta.10) — test list

Source: `docs/superpowers/specs/2026-10-28-p24-beta10-design.md`. Tests are written first, then the build. Nothing here is run on the author's laptop; CI / the maintainer runs it.

## Conventions followed

- Host unit: `#[cfg(test)]` in `crates/host/src/monitor.rs` (helpers `monitor(name, primary, size)`, `laptop()`, `projector()`, `tv()`, `scaled_tv()`, `StageDisplay::monitors_changed(list, wanted, reattach, play_is_open)`). Host integration: `crates/host/tests/<name>.rs` (helpers copied from `stage_mirrors.rs`: `monitor`, `key`, `desk()`, `loaded()`). New file: `crates/host/tests/beta10.rs` (window-close policy, hand move, placement verify, macOS keys). App crate unit: `#[cfg(test)]` beside the code in `crates/app/src` (source-sweep style as `nothing_but_the_command_opens_the_statistics_window`).
- Studio: page tests in `apps/studio/src/pages/beta10.test.tsx` (`render(<App />)`, `createFakeHost()`, `fake.seed(demoLibrary(), [demoRecipe()])`, `setHostTransport(fake)`, `useNavStore.setState({ route: HOME, … })`, `useWindowsStore.setState({ statsOpen: null, stageOn: null, stageMirrors: [] })`, `demoMonitors`); component tests beside the component (`MonitorsSettings.test.tsx`, `SidebarNav.test.tsx`, `QuitGuard.test.tsx`).
- New seams the design asks for (names are proposals; the build may rename, the assertion stands): `StageDisplay::window_destroyed(WindowRole) -> WindowClosed`, `StageDisplay::remove_display(&key) -> RemoveOutcome`, `StageDisplay::close_stage()`, `StageDisplay::hand_moved(WindowRole, Option<MonitorKey>)`, `monitor::verify_placement(target, actual, attempt) -> Verdict`, `monitor::macos::display_key(localized_name, w, h)`, `monitor::mirror_sets(...)`. `WindowRole = Pacer | Mirror(MonitorKey) | Stats`.
- jsdom has no layout and no Tauri window; the title-bar controls are tested against a stubbed `@tauri-apps/api/window` (`getCurrentWindow()` returning `minimize/toggleMaximize/close/isMaximized/isFullscreen/onResized` spies) and a stubbed platform helper (`isMac`), as the status-pill/quit tests stub the host.
- The macOS window path cannot run on Windows; everything about it is asserted on the pure parts. The manual list at the end covers the rest.
